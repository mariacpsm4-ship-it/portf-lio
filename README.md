 Portfólio 

Este repositório apresenta meu portfólio escolar, desenvolvido durante o curso Técnico em Informática.

O objetivo é reunir e apresentar alguns dos trabalhos e projetos que desenvolvi ao longo dos estudos, demonstrando meus conhecimentos e minha evolução nas atividades práticas.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- XAMPP
- Python
- Banco de Dados

Projetos desenvolvidos

 1. Primeiro trabalho escolar
Projeto desenvolvido durante as atividades do curso Técnico em Informática.

 2. Segundo trabalho escolar
Trabalho prático desenvolvido para aplicar os conhecimentos adquiridos em aula.

 3. Projeto de Banco de Dados

Desenvolvimento de um sistema com banco de dados utilizando o XAMPP e o Visual Studio Code, com integração ao Python.

O projeto teve como objetivo armazenar e organizar informações inseridas pelo usuário no sistema, trabalhando conceitos de banco de dados e integração entre tecnologias.

 Sobre o portfólio

O site foi desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de apresentar meus conhecimentos, tecnologias estudadas e projetos escolares.
 Autoria

Projeto desenvolvido como atividade do curso Técnico em Informática.
